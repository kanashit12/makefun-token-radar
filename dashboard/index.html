How the model works

Implied value is the entry's own claim, never make.fun's. It follows only from the snapshot's own figures — TVL, seven-day growth, how long the protocol has run with no token, and how many chains it runs on — priced off the market's own comparables.

implied = TVL × multiple × growth × maturity × breadth
multiple   median mcap/TVL of live protocols in the same category (≥3),
           else the median across all live protocols; clamped to [0.02, 1.50]
growth     1 + clamp(change_7d, −50, +100)% × 0.5                 in [0.75, 1.50]
maturity   0.7 + min(age_days, 1095) / 1095 × 0.3                 in [0.70, 1.00]
breadth    1 + 0.02 × min(chains − 1, 5)                          in [1.00, 1.10]

What the board does not do

  • It does not predict whether or when a protocol issues a token. A protocol on the board records no token in DefiLlama's snapshot; that is not proof it has none.
  • It never special-cases a protocol by name. The same function scores every row, and the page recomputes each row's implied value from the snapshot figures and checks it against board.json.
  • Wrapped, staked and bridged products of a token that already trades are kept off the board, as is any protocol whose token already trades — those live in the Live tokens view.
  • Farm plans are steps with a cost and a time, derived from the protocol's category, chains, TVL and age. Never pay to claim: a real claim costs gas only, from the protocol's own page.
